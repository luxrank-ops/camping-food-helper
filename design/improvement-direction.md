# 디자인 개선방향 — 시각적(Visual) / 비주얼

> 기준: 2026-10-16 / 현재 `design/` PNG + `index.html` `:root` 디자인 시스템 기준
> 방향: 야외 캠핑 환경(밝은 햇빛/반사) + 한 손 조작 + 빠른 정보 확인

---

## 1. 기존 강점 (유지)
- 컬러: 깊은 숲 다크(`--bg:#0E2820`) + 크림 카드 + 오렌지 CTA(`--cta:#F4735A`)
- 폰트: `Do Hyeon`(디스플레이) + `Gothic A1`(본문) — 한글 가독성 우수
- 테마: 다크/라이트 `data-theme` 자동 지원 + `prefers-color-scheme`
- 터치: 44px 이상 영역 의식, 카드 그림자(`--shadow`)로 깊이감

---

## 2. 개선 포인트 (3가지)

### A. 야외 가시성 / 정보 계층
- **문제**: 다크 배경은 야간 캠핑에 좋으나, 낮 야외 햇빛에서는 화면이 어둡고 카드가 흐릿해 보일 수 있음.
- **개선**: 
  1. `data-theme="light"`를 기본/자동으로 강화 (기존은 이미 있음,UI 토글 버튼 추가 권장)
  2. 상단 날씨/메뉴 영역은 **크림/화이트 카드(`--surface`)로 고정**하여 항상 명확히 보이게
  3. 체크리스트 항목은 **완료 시 스트라이크 + 연한 회색**으로 구분 명확히

### B. 메뉴 이미지 / 콘텐츠 시각
- `design/series-1-menu-budae.png` 등 메뉴 사진 활용 시:
  - 둥근 모서리 `border-radius: 16px`
  - 하단 그라데이션 오버레이 (`linear-gradient(to top, rgba(0,0,0,.5), transparent)`) → 흰 텍스트 가독성 확보
  - 태그(국물/한 냄비/짧은 조리)는 현재 `--chip` → **배경 `#EAF0E6`, 텍스트 `#2D4A3E`, 폰트 12px 700**으로 통일

### C. 플로팅 액션 / 하단 내비게이션
- **현재**: 주요 CTA는 화면 중앙 하단 버튼
- **개선**: 오른쪽 하단 **원형 플로팅 버튼(64px)**으로 이동 → 한 손 조작 시 엄지 위치 최적화
- 하단 탭 아이콘(추천/준비물/내 정보)는 **채워진 아이콘 + 활성 상태 오렌지**로 통일

## 3. 디자인 토큰 정리 (구현 시 참고)

```css
/* 개선 제안 토큰 — 기존 :root에 추가/조정 */
--surface-light:#FFFFFF;          /* 야외 밝은 모드 카드 */
--card-radius:max(16px, 1rem);    /* 둥글기 통일 */
--text-hero:1.35rem;              /* 메뉴 이름 */
--tag-text:0.75rem;              /* 태그 폰트 */
--fab-size:4rem;                 /* 플로팅 버튼 */
--shadow-card:0 8px 24px rgba(20,41,31,.12); /* 라이트 그림자 */
```
